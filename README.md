# Sofra Assets

High-resolution, lightweight WebP food assets for the **Sofra** Turkish Cookbook application.

Served via jsDelivr CDN:
`https://cdn.jsdelivr.net/gh/shanimoglu/sofra-assets@main/recipes/{recipe_id}.webp`

## Directory Structure
- `recipes/`
  - `main_01.webp` .. `main_15.webp` (Ana Yemekler)
  - `soup_01.webp` .. `soup_15.webp` (Çorbalar)
  - `bake_01.webp` .. `bake_15.webp` (Hamur İşleri & Kahvaltılık)
  - `meze_01.webp` .. `meze_15.webp` (Mezeler)
  - `dessert_01.webp` .. `dessert_15.webp` (Tatlılar)
  - `veggie_01.webp` .. `veggie_15.webp` (Zeytinyağlılar)
